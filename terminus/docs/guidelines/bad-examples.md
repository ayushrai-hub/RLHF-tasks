# Bad Example Tasks

## Too Easy

> Write a function that reverses a string.

One-liner — agents solve instantly.

## Too Vague

> Build a web scraper.

No verifiable requirements.

## External Dependencies

> Query the Twitter API.

Requires credentials/network.

## Ambiguous

> Make this code better.

Subjective without metrics.

## Prompt Anti-Patterns

| Pattern | Why bad |
|---------|---------|
| Step-by-step with exact values | Gives the answer |
| Detection/hints sections | Leaks strategy |
| API spec markdown dumps | Synthetic, not human |
| Prescriptive file signatures | Removes reasoning |
| Bold solution fragments | Highlights answers |

See [prompt-styling.md](prompt-styling.md).

## Task Inspiration

- Concurrency bugs, race conditions, deadlocks
- Algorithms with constraints
- Refactoring with measurable goals
- Security vulnerabilities
- Performance optimization with benchmarks
