Implement the neural-echo-forge Rust CLI under /app so it ingests multi-session LLM conversations, tool invocation logs, user profiles, and memory policies from /app/data/, stages conversational memory at /app/state/memory-snapshot.json, reconciles staged state at /app/state/reconcile-report.json, and exports deterministic memory artifacts into /app/output/. Build to /app/neural-echo-forge. Run neural-echo-forge with no arguments to execute ingest, then reconcile, then export, or use the ingest, reconcile, and export subcommands separately. Export alone must exit 2 when /app/state/memory-snapshot.json or /app/state/reconcile-report.json is missing.

Ingest must parse session transcripts, tool rows, profile baselines, and policy limits per /app/docs/memory-contract.md and the companion schemas under /app/docs/. Write /app/state/ingest-staging.json with candidate digest, conflict_mode, and export_mode before writing the snapshot per /app/docs/ingest-staging.md. Stage resolved memories with temporal precedence, explicit correction overrides, semantic deduplication, and retention classification into active_memories and retention_vault before writing the snapshot. Each successful ingest increments snapshot_seq and refreshes ingest_fingerprint per /app/docs/memory-snapshot.md. Reconcile must validate snapshot and staging coupling and write reconcile-report.json per /app/docs/reconcile-contract.md. Export must read the staged snapshot, ingest staging ledger, and reconcile report only, apply export-time quota trimming and retrieval index ordering documented in /app/docs/export-artifacts.md and /app/docs/retention-policy.md, and write /app/output/memory-records.json, /app/output/retrieval-index.json, and /app/output/memory-audit.json. Export fails when ingest-staging.json is missing, when staging_seq does not match snapshot_seq, or when reconcile-report.json is missing or stale. conflict_mode governs ingest conflict and semantic dedup tie-breaking per /app/docs/conflict-resolution.md and /app/docs/semantic-dedup.md; export_mode governs export-time quota only per /app/docs/retention-policy.md. Profile baseline memory_id assignment, malformed-row counting, and discovery_seq assignment are normative in /app/docs/session-schema.md. When NEF_POLICY_PATH is set it must be an absolute path or ingest exits 2.

Re-running on unchanged inputs must yield byte-identical snapshot and output files except snapshot_seq and memory-audit export_generation, which advance with each successful ingest. Skip malformed JSONL rows per the contract; ingest and the default ingest-reconcile-export run exit 3 when any row was skipped while still writing outputs from valid records, but the export subcommand alone exits 0 on success regardless of the snapshot lines_skipped value. The legacy memory wrap helper under /app/src/staging/memory_wrap.rs, the profile bind helper under /app/src/ingest/profile_bind.rs, the memory seal helper under /app/src/export/memory_seal.rs, and the reconcile gate helper under /app/src/export/reconcile_gate.rs are not authoritative for staged or exported output. Only serde, serde_json, and sha2 may appear in Cargo.toml dependencies. The verifier rebuilds /app/neural-echo-forge from the current Rust tree before scoring and may mutate session shards with echo-mutate --seed or supply hidden conversation fixtures at test time; do not hardcode outputs.
