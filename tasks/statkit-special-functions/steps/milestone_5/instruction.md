Last stage for statkit at `/app`. All the distribution, quantile, and Kolmogorov functions from the earlier stages should already be working.

Wire up the `statctl` CLI so it actually runs a test suite. Implement the `.spec` parser in `/app/cli/specparse.c` and the driver in `/app/cli/statctl.c` so that `build/statctl <spec> [-o <out>]` reads a suite, runs each test, and writes the JSON report. Three test kinds: chi-square goodness-of-fit, the Welch two-sample t-test (unequal variances, non-integer degrees of freedom), and a one-sample Kolmogorov-Smirnov normality test. On top of the per-test statistic and p-value, the report carries a Holm-Bonferroni adjusted p-value and reject decision across the suite, a chi-square critical value for each GOF test, and a confidence interval for each Welch test. The spec grammar, the exact statistic / df / p-value definitions for all three kinds, the malformed-block rules, the Holm correction, the intervals, and the report schema are all in `/app/docs/FORMAT.md`. Default output path is `/app/output/report.json`.

Build everything with `make` from `/app`. There are sample suites under `/app/data/fixtures` to try. Don't modify the headers, `/app/tests`, or `/app/data`.
