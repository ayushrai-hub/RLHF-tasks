Inside /app/marrow is a deterministic Java lossless compression codec. Its sources are under src/marrow, the public command entry point is marrow.Main, and MARROW_SPEC points to the exact format contract.

Assume the bit I/O, CRC-32, and LZ77 primitives are already correct. Complete the entropy and container responsibilities in src/marrow/Huffman.java, src/marrow/HuffCoder.java, src/marrow/BlockCodec.java, and src/marrow/Container.java.

Frequency-based Huffman length generation must be deterministic. Equal weights are resolved by stable tags: leaf nodes use their symbol values, and internal nodes use increasing tags in creation order. An alphabet with one used symbol assigns that symbol length 1, while an empty alphabet has no nonzero lengths. The huff report includes only nonzero code lengths, ordered by symbol, followed by the count.

Canonical codes must be reconstructed entirely from the length table, with the most significant bit emitted before lower-order bits. Unusable canonical length tables must be rejected wherever canonical codes are built or consumed. Compressed block data starts with the 258-byte length table and continues with token symbols, raw match length bits, raw match distance bits, and one end-of-block symbol. After that end-of-block symbol, only zero padding in the final byte is valid. Block decoding must recover the token stream and reconstruct bytes through the LZ decoder.

Container handling must honor the MRW1 stored and compressed flags, big-endian unsigned 32-bit original size, standard CRC-32, and payload bytes. Stored containers contain the raw input whenever the compressed block is not smaller than the original. Decompression must reject bad magic, unknown flags, decoded-size mismatches, CRC mismatches, malformed compressed blocks, unusable canonical tables, invalid match boundaries, and trailing block data with clean Marrow errors and no standard output. Failed decompression must preserve an existing requested output file and must not create a missing requested output file. Inspect reports exactly magic, flag, original_size, crc32, container_size, and payload_size without fully decoding payload bytes; it still rejects short headers, bad magic, and unknown flags, while valid stored or compressed headers remain inspectable even when decompression would reject their payload, size, or CRC. Successful huff, huffround, compress, decompress, and inspect commands write reports to standard output without error output; huffround reports symbol and encoded-byte counts, and compress and decompress report input and output byte counts. Independent Marrow implementations must interoperate with this Java codec.
