The Vera Institute of Justice publishes county level United States jail and prison populations by year under `/app/environment/data/states`, one file per state. The files are not clean: a county and year is often split across several correction rows so no single row is complete, `fips` is stored without the leading zero that low numbered states need, the counts are often missing or not whole, and `urbanicity` is written inconsistently across a county's years.

Edit the starter at `/app/environment/analysis.R` so that running it reads those files, reconciles each county and year into one record, resolves each county to a single urbanicity label, and writes two cleaned tables into `/app/environment/outputs`: `county_year_clean.csv`, the one row per county and year panel, and `urbanicity_summary.csv`, which for each urbanicity group reports a typical jail and prison rate pooled across the group's states with a random-effects estimator that treats each state as one study and accounts for how much the states disagree. That directory is cleared on each run, so every result must come from the analysis itself.

The exact columns, the reconciliation and tiebreak rules, the rate formula, and the rounding modes for both outputs are specified in `/app/environment/OUTPUT_CONTRACT.md`. Follow it exactly.
