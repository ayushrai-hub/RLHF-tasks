The signing team needs /app/tools/entitlement_audit.py to audit the Objective-C app bundles under /app/bundles. Keep the CLI self-contained and runnable with Python 3. Bundles may be plain directories rather than `.app`-suffixed directories; identify a bundle by an `Info.plist` file inside a child directory of /app/bundles. Each bundle stores app metadata in its Info.plist; use the ProvisioningProfile key for the profile value. For entitlements, prefer the bundle sidecar named `<CFBundleExecutable>.entitlements` when it exists; otherwise use the first available `*.entitlements` plist sidecar sorted alphabetically.

Milestone 1: Implement `python3 /app/tools/entitlement_audit.py inventory /app/bundles /app/out/entitlement-inventory.json`. The output must be JSON with `bundles` sorted by bundle id and a `summary`. Each bundle row must include `path`, `bundle_id`, `display_name`, `executable`, `platform`, `profile`, and `entitlements`. Normalize `iphoneos` to `ios` and `macosx` to `macos`; entitlement arrays must be sorted strings. The entitlement object must expose `app_groups`, `keychain_groups`, `associated_domains`, `aps_environment`, and `team_identifier`, using empty arrays or null for missing values. `team_identifier` must come only from the `com.apple.developer.team-identifier` entitlement key; do not infer it from keychain group prefixes or any other field. The summary must include `total`, `by_platform`, `with_push` (count of bundles whose `aps_environment` is not null), and `missing_team_identifier`.
