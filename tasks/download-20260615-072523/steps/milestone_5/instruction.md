Milestone 5: Implement `python3 /app/tools/entitlement_audit.py verify-remediation /app/bundles /app/policy/signing-policy.json /app/out/entitlement-verification.json`. The command must reuse the same bundle discovery, entitlement sidecar selection, effective policy override, classification, remediation, and current-filesystem rules from the earlier milestones. It must not modify any file.

The output must be JSON with `bundles`, `summary`, and `violation_counts`. Sort bundle rows by status severity (`blocked`, then `drift`, then `compliant`) and then by bundle id. Each bundle row must include `bundle_id`, `platform`, `profile`, `status`, `reasons`, `selected_sidecar`, `needs_changes`, `blocked`, `effective_policy`, `current`, and `pending_changes`.

Use `blocked` when the current plan action is `block`. Use `drift` when the current plan action is `update` and at least one safe entitlement-sidecar change is still pending. Use `compliant` when no current policy violation remains. `selected_sidecar` is the absolute path to the chosen entitlement sidecar, or null when no sidecar exists. `needs_changes` is true only for `drift` rows. `blocked` is true only for `blocked` rows.

`effective_policy` must include `team_identifier`, `allowed_profiles`, `expected_push_environment`, `required_app_group_prefix`, and `allowed_associated_domain_suffixes`. `current` must include `team_identifier`, `app_groups`, `associated_domains`, and `aps_environment` from the current selected entitlement sidecar after normalizing arrays as sorted strings and missing scalar values as null. `pending_changes` must include `set_team_identifier`, `remove_app_groups`, `remove_associated_domains`, and `set_aps_environment`. `set_aps_environment` is the effective expected push environment only when a push-environment change is currently pending; otherwise it is null.

`summary` must include integer `total`, `compliant`, `drift`, `blocked`, `files_needing_changes`, `safe_change_count`, and `blocked_with_sidecar`. `files_needing_changes` is the number of `drift` rows with a selected sidecar. `safe_change_count` is the total count of pending app-group removals, associated-domain removals, and push-environment sets across `drift` rows. `blocked_with_sidecar` is the number of blocked rows whose selected sidecar is not null.

`violation_counts` must include every reason label from planning with integer counts, including zero-count labels: `team identifier missing`, `team identifier mismatch`, `profile not allowed for platform`, `app group prefix violation`, `associated domain not allowed`, and `push environment profile mismatch`.
