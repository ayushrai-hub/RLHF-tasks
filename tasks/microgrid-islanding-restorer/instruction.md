The storm desk needs a feeder-to-island restoration plan for /app/task_file/input_data. Each line of /app/task_file/input_data/feeders.jsonl is one feeder, and /app/task_file/input_data/config.json defines island capacities, mandatory feeders, district floors, resilience floors, and the scoring normalizer. Write /app/task_file/output_data/restoration_plan.json as JSON shaped like {"assignments":[{"feeder_id":"F01","island_id":"NORTH"}]}; omitted optional feeders stay unrestored.

A plan scores zero if a feeder is assigned twice, a mandatory feeder is missing, an unknown island is used, any island exceeds its kw/surge/fault caps, an island misses one of its required districts, an island is below its resilience floor, the global district floors are missed, or any same-island feeder pair violates the microgrid_resonance_index rule. The base score is restored value divided by score_normalizer. The strict score also requires every island to carry at least one critical feeder and load_balance_score to be at least 0.32.

Your result must reach total_score >= 0.98 and total_score_strict >= 0.96. The verifier may rerun the compiled program against an altered config with a changed mandatory set and district floor, so read the input fresh rather than replaying a saved assignment. Build from /app/task_file with cd /app/task_file && GOPROXY=off go build -o microgrid_restorer ./src; the binary must be /app/task_file/microgrid_restorer and must accept optional input and output directory arguments.
