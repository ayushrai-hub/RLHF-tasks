We are ready to deploy the background worker that processes incoming sky camera frames and records the final triage decisions. Please write and compile a Kotlin program at `/app/src/TriageWorker.kt` that reads `/app/terraform/outputs.json` for the input and prediction directories, loads `/app/output/protocol-decisions.json` for the rules, and loads `/app/models/classifier.bin` for the classifier parameters.

For each PNG frame in the incoming directory, parse the matching metadata JSON, classify the image, and then apply the protocol rules in priority order. The untrusted sensor quarantine rule takes priority over everything else; otherwise weak aurora events below the approved temperature threshold quarantine, strong aurora events at or above the approved probability threshold escalate, and all remaining frames archive.

Write one result file per frame under the configured predictions directory using the filename pattern `[frame_id]_result.json`. Each result must include `frame_id`, `aurora_class`, `probability`, `action`, and `flagged`. Also write `/app/output/run_summary.json` with integer counts for `total_processed`, `escalated_count`, `quarantined_count`, and `archived_count`.

The worker will be run repeatedly during operations, sometimes with relocated incoming and prediction directories from `/app/terraform/outputs.json`. Treat each run as a fresh snapshot: remove old `*_result.json` files from the configured predictions directory before writing results, then base the summary only on frames present in the configured incoming directory for that run.
