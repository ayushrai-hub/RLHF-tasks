The January 2024 Pacific Seafloor Observatory Network pressure telemetry lives in `/app/data/sensors.db`. Station calibration coefficients, detection thresholds, maintenance windows, output schema, and the full event-detection methodology are documented in `/app/docs/seismology_ops_dossier.md`.

Build a TypeScript CLI (compile to `dist/src/index.js`, invoke as `node dist/src/index.js --db <path> --dossier <path> --output <path>`) that reads the supplied database and dossier, applies the dossier's calibration and slow-slip detection pipeline (detrending, robust Z-scores, Bayesian change-point scoring), and writes a JSON event catalog to `/app/output/events.json`. Follow the dossier's inclusion and exclusion rules; use it as the source of truth for catalog fields, station coverage, and maintenance-window handling. The CLI must derive results from the inputs you are given — do not emit a static catalog. TypeScript helpers and database utilities under `/app/src/` are available; build with `npm run build`.
