Build the time-domain wave engine on top of the model and source layer from the previous step: a 2D P-SV elastic finite-difference solver on a staggered grid, with a polynomial PML absorbing zone at the model edges and a single-mechanism viscoelastic correction driven by the per-cell quality factors.

Add a `simulate` subcommand, `seismic simulate <input.json> <output_dir>`. Recover the Lame parameters from the rasterised grids using `lambda = rho*(vp^2 - 2*vs^2)` and `mu = rho*vs^2`, march a velocity-then-stress staggered update across `n_steps` time-steps, inject the source as pressure (added equally to sigma_xx and sigma_zz) or vertical-velocity, apply the polynomial PML damping zone on all four boundaries when enabled, and apply the SLS multiplier `exp(-pi * f_ref * dt / qp)` per step when attenuation is enabled. Sample vz at every receiver every step and write `shot_gather.npy` of shape `(n_steps, n_receivers)`, `time.npy` of shape `(n_steps,)` (starting at zero), and zero-padded snapshots `snapshots/snap_TTTTTT.npy` of shape `(nz, nx)` whenever `snapshot_interval > 0`, at step indices strictly less than `n_steps`. The full per-field schema lives at /app/docs/simulate_schema.md.

Each simulate config names the rasterised model directory and source wavelet it consumes through its `model_dir` and `source.path` fields, both of which live under /app/output. Generate those grids and wavelets first with the milestone 1 `model` and `source` subcommands so every model directory and source file a simulation references already exists, then run `simulate` to write each run's outputs to the directory given on the command line. The fixture JSONs under /app/fixtures carry the full grid, source, receiver, PML, and attenuation configuration for every run.
