I need a package dependency version resolver at /app/solver.go, reads commands from stdin and writes to stdout. You can build it with cd /app && go build -o /app/solver /app/solver.go && /app/solver

PUBLISH pkg version registers that a version exists for a package in semver format major.minor.patch, prints OK. YANK pkg version marks a version as yanked so resolution ignores it, prints YANKED pkg version. DEPEND pkg version depPkg constraint declares that pkg at version depends on depPkg matching the constraint. Supported constraints are ^X.Y.Z (compatible, same major but minor and patch can increase), ~X.Y.Z (same major.minor, patch can increase), >=X.Y.Z (at least that version), a bare X.Y.Z for exact match, or a range like >=X.Y.Z <A.B.C. Prints OK. ADD pkg constraint adds a top-level requirement with that constraint, prints OK.

RESOLVE finds a compatible version for every added package satisfying all constraints at once, picking the highest compatible non-yanked version for each. Dependencies of selected versions must also resolve transitively, and if multiple packages depend on the same transitive dep, ALL their constraints must be satisfied simultaneously (intersection). When the highest version of a package causes a transitive conflict, the solver must backtrack and try the next lower version. On success print RESOLVED then one line per package alphabetically as pkg version. If no valid combination exists print CONFLICT with the package and constraint that failed. LOCK pkg version pins a version so RESOLVE always uses it, prints LOCKED pkg version. If it violates an existing constraint print LOCK_ERROR pkg version instead. UNLOCK pkg removes a lock, prints UNLOCKED pkg. If no lock exists prints UNLOCK_ERROR pkg. UPGRADE pkg tries to move a locked package to the highest compatible version without breaking anything, prints UPGRADED pkg newVersion or NO_UPGRADE if already at the best. REMOVE pkg removes the package from top-level requirements and any lock, prints REMOVED pkg. RESOLVE after REMOVE no longer includes that package unless it appears as a transitive dependency.
