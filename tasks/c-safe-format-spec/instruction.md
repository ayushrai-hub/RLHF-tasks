The C library under /app/environment is sfmt, a small type-checked formatting and diagnostics toolkit. Everything that renders text, the logger, the field encoder, the hex dumper, funnels through one function that is not written yet: sf_format in /app/environment/src/format.c, which right now just returns SF_ERR_NOT_IMPLEMENTED. Implement it.

The exact contract is at /app/environment/docs/sfmt-spec.md. Follow it to the letter, because the output is compared byte for byte. sfmt renders a format string against a typed argument array rather than a C va_list, and it departs from the C library in several places: it refuses %n, it adds binary and underscore-grouped decimal conversions, it prefixes octal and binary alternate forms with 0o and 0b, it groups the leading zeros when zero padding a grouped decimal, it takes width and precision from arguments with * and .*, and string precision counts UTF-8 code points rather than bytes. Do not forward the format string to printf or snprintf; it disagrees with the contract. Worked input to output pairs are under /app/environment/testdata/examples.

Build from /app/environment with make. The compiler is on PATH and there is no network, so do not try to install anything. The tool reads one vector file and writes the rendered bytes: sfmt fmt <file>. When it works, leave a short security_notes.md at /app/environment/security_notes.md naming the class as an uncontrolled format string (CWE-134), the %n write primitive, and the type-checked, no-va_list design.
