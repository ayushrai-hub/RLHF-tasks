The command runner in `/app` needs a way for a justfile to declare the minimum runner version it supports. Add a `minimum-version` setting that accepts a plain string literal in `MAJOR.MINOR.PATCH` form. If the running binary is older than the declared version, command evaluation should stop before recipes run and print a clear diagnostic that includes the required version and the current version. For a requirement such as `999.1.2`, the diagnostic should include text like `requires just 999.1.2 or later` along with the current version and `minimum-version`.

Compatible or older requirements should let recipes run normally, including requirements equal to the current binary version. Invalid version strings, shell-expanded strings, indented strings, and computed expressions must be rejected with user-facing diagnostics. Invalid semantic versions should include text like `invalid version \`one.two.three\``, and non-plain string forms should include text like `must be a plain string literal`. Keep existing settings, recipe execution, `--dump`, and version reporting behavior working.
