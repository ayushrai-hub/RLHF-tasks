The cutover review tool in `/app` is supposed to turn PostgreSQL schema dumps, publication SQL, and subscriber snapshots into a stable catalog that release engineers can inspect before changing logical replication.

Start by repairing `pubgate parse`. It should accept `--schema <sql> --publications <sql> --subscriptions <json> --db <sqlite> --out <json>` from arbitrary absolute paths, create output parent directories, and write pretty JSON with a trailing newline. The parser needs to retain empty publications, table-level publication column lists, subscriber target columns, inline and table-level primary key flags, data types with modifiers, nullability, and `REPLICA IDENTITY FULL` markers. It should also populate SQLite tables for schemas, columns, publications, publication table membership, subscriptions, and subscription table targets so operators can inspect the catalog with `/app/scripts/show_catalog.sh`; JSON arrays stored inside SQLite text columns are compact single-line JSON. The exact snapshot object shapes are in `/app/docs/snapshot_contract.md`.
