# Docker network connectivity replay rules (read-only specification)

Implement these rules in Go under `/app/cmd` and `/app/internal` only; do not edit this file or other files under `/app/docs/`.

Fixtures live under `/app/data` as `docker_network_connectivity_debugger_scenario_XX.json` (01–36) plus `/app/data/docker_network_connectivity_debugger_scenario_XX/docker_network_connectivity_debugger_capture.cnx` (CNX1 little-endian per `DOCKER_NETWORK_CONNECTIVITY_DEBUGGER_CAPTURE_FORMAT.md`). JSON files hold scenario defaults only (no `events` array). `/app/data/docker_network_connectivity_debugger_manifest.json` lists `scenarios` in processing order.

## Package layout

Go sources live under `/app/internal` in these packages (do not invent alternate paths such as `capture` or `replay` at the repo root):

| Package directory | Role |
|-------------------|------|
| `docker_network_connectivity_debugger_capture` | CNX1 `Decode` |
| `docker_network_connectivity_debugger_replay` | connectivity replay and report rows |
| `docker_network_connectivity_debugger_policy` | `policy_overrides` boolean resolution |

Entry point: `/app/cmd/docker-network-connectivity-debugger/main.go`.

## Quick reference (read first)

**`operation` on findings**

| Finding kinds | `operation` value |
|---------------|-------------------|
| `CONNECT_PROBE` steps 1–2 only (`UNKNOWN_CONTAINER` for missing target or source) | `""` (never the protocol) |
| `DNS_UNRESOLVED`, `NETWORK_PARTITION`, `PORT_UNPUBLISHED`, `EGRESS_DENIED`, `ZONE_BLOCKED`, `TLS_REQUIRED` | probe protocol **uppercased** (`tcp` → `TCP`) |
| All other kinds, including post-replay audits | `""` |

**Post-replay audit `event_seq`:** `max(seq from every decoded capture event) + 1` per scenario (never `0`, never a shared constant). Applies to `BRIDGE_GAP`, `OVERLAY_ASYMMETRY`, `OPEN_DMZ_PATH`, `INSPECT_UNBOUND`.

**Event replay order:** sort `(seq, sort_key, event_id)`; dedup duplicate `event_id` (first wins). See sort_key table under Event ordering.

**`/app/build/` output:** only `docker-network-connectivity-debugger` and `docker_network_connectivity_debugger_report.json` (no validation copies or extra JSON).

**`connectivity_risk`:** from container `zone` only; findings never change it.

**`TLS_REQUIRED`:** only when target zone is `internal`, target has `net:tls` label, `require_tls_on_internal` is true (after `policy_overrides`), and probe `use_tls` is false.

**`policy_overrides`:** boolean map applied on top of scenario defaults before replay (`block_edge_to_internal: false` allows edge→internal probes).

**`REGISTER_DNS`:** later rows for the same `network_id` and `alias` replace earlier alias targets (idempotent overwrite).

**`CONNECT_PROBE` check order:** steps 1–8 in the CONNECT_PROBE section below; step 6 `EGRESS_DENIED` always runs before step 7 `ZONE_BLOCKED` when both could apply.

**`finding_id`:** `{scenario_id}::{entity_id}::{event_seq:04d}` only — never append disambiguation suffixes when entity and `event_seq` collide (duplicate `finding_id` values in the array are allowed).

**Findings sort ties:** Sort by `finding_id` ascending only. When multiple findings share the same `finding_id`, preserve their append order (stable sort). Never secondary-sort by `kind`, `entity_id`, or `detail`. Example: `docker_network_connectivity_debugger_scenario_19` lists `OPEN_DMZ_PATH` before `INSPECT_UNBOUND` when both share one `finding_id`.

## Scenario defaults

- `require_shared_network` (bool, default true when the field is omitted from JSON)
- `block_edge_to_internal` (bool, default true when omitted)
- `require_tls_on_internal` (bool, default true when omitted)
- `policy_overrides` (optional): may override any boolean above

Apply `policy_overrides` on top of defaults before replay.

## Event ordering and deduplication

Sort events ascending by `(seq, sort_key, event_id)`. Drop later rows with a duplicate `event_id` (first wins). Count skipped duplicates in `duplicate_events_skipped`.

The middle sort field `sort_key` is **not** always `container_id`. Use this table:

| Event kind | `sort_key` value |
|------------|------------------|
| `REGISTER_CONTAINER`, `JOIN_NETWORK`, `LEAVE_NETWORK`, `PUBLISH_PORT`, `BIND_LABEL`, `REGISTER_DNS` | `container_id` |
| `CREATE_NETWORK` | `network_id` (often empty `container_id` in captures) |
| `ALLOW_EGRESS`, `REVOKE_EGRESS` | `to_container` |
| `CONNECT_PROBE` | `target_id` |

When `seq` and `sort_key` tie, break ties by `event_id` ascending.

## Container state

Per `container_id`: `zone` (`internal`, `edge`, or `dmz`), `labels` (set of strings from `BIND_LABEL`), `published_ports` (set of `"{port}/{protocol}"` from `PUBLISH_PORT`, protocol defaults to `tcp` when omitted).

Global `networks`: map `network_id` → `driver` (`bridge` or `overlay`) via `CREATE_NETWORK`.

Global `memberships`: container `container_id` joined to `network_id` (from `JOIN_NETWORK`; removed by `LEAVE_NETWORK`).

Global `dns`: per `network_id`, map `alias` → `container_id` from `JOIN_NETWORK` optional `alias` and from `REGISTER_DNS` (`REGISTER_DNS` overwrites any prior alias on that network).

Global `egress_rules`: directed edges `from_container→to_container` via `ALLOW_EGRESS` (removed by `REVOKE_EGRESS`).

## REGISTER_CONTAINER

Fields: `container_id`, `zone`.

If `container_id` already exists → `DUPLICATE_CONTAINER` (no mutation). Else create container with empty labels and published ports.

## CREATE_NETWORK

Fields: `network_id`, `driver` (`bridge` or `overlay`).

If `network_id` already exists → `DUPLICATE_NETWORK` (`entity_id` = `network_id`, `detail` = empty). Else record network.

## JOIN_NETWORK

Fields: `container_id`, `network_id`, optional `alias`.

Missing container → `UNKNOWN_CONTAINER` (`entity_id` = `container_id`, `detail` = event kind).

Missing network → `UNKNOWN_NETWORK` (`entity_id` = `network_id`, `detail` = event kind).

If `(container_id, network_id)` membership already exists → `DUPLICATE_JOIN` (`entity_id` = `container_id`, `detail` = `network_id`). Else record membership. If `alias` is non-empty, store on that network for this container (overwrites prior alias for same container on that network).

## LEAVE_NETWORK

Fields: `container_id`, `network_id`. Unknown container or network → same as `JOIN_NETWORK`. If membership absent → no finding. Else remove membership and clear aliases for that container on that network.

## PUBLISH_PORT

Fields: `container_id`, `port` (int), optional `protocol` (default `tcp`).

Missing container → `UNKNOWN_CONTAINER` (`entity_id` = `container_id`, `detail` = event kind). Else add port (idempotent).

## BIND_LABEL

Fields: `container_id`, `label` (non-empty).

Missing container → `UNKNOWN_CONTAINER` (`entity_id` = `container_id`, `detail` = event kind). Else add label (idempotent).

## ALLOW_EGRESS

Fields: `from_container`, `to_container` (both non-empty).

If either endpoint is unknown → `UNKNOWN_CONTAINER` (`entity_id` = missing id, `detail` = event kind).

If directed edge already exists → `DUPLICATE_EGRESS` (`entity_id` = `to_container`, `detail` = **`from_container`**, never empty). Else record edge.

## REVOKE_EGRESS

Fields: `from_container`, `to_container`. Unknown endpoints → same as `ALLOW_EGRESS`. If edge absent → no finding. Else remove edge.

## REGISTER_DNS

Fields: `network_id`, `alias`, `container_id`.

Missing network → `UNKNOWN_NETWORK` (`entity_id` = `network_id`, `detail` = event kind).

Missing container → `UNKNOWN_CONTAINER` (`entity_id` = `container_id`, `detail` = event kind).

Else record alias on that network (idempotent).

## CONNECT_PROBE

Fields: `source_id`, `target_id`, `port` (int), optional `protocol` (default `tcp`), optional `dns_alias` (default `""`; JSON field name is `dns_alias`, not `target_alias`), `use_tls` (bool).

Shared networks between two containers are the sorted intersection of their `JOIN_NETWORK` memberships.

Evaluate in this **fixed order**. Emit **at most one** finding per `CONNECT_PROBE` event: as soon as a step matches, record that finding and **do not** evaluate later steps for the same event.

1. Missing `target_id` registration → `UNKNOWN_CONTAINER` (`entity_id` = `target_id`, `detail` = event kind, `operation` = `""`). Check `target_id` **before** `source_id`.
2. Missing `source_id` registration → `UNKNOWN_CONTAINER` (`entity_id` = `source_id`, `detail` = event kind, `operation` = `""`).
3. `dns_alias` non-empty: if no shared network has that alias resolving to `target_id` → `DNS_UNRESOLVED` (`entity_id` = `source_id`, `detail` = `dns_alias`, `operation` = **uppercased** protocol e.g. `TCP`).
4. `require_shared_network` and the shared-network set is empty → `NETWORK_PARTITION` (`entity_id` = `target_id`, `detail` = `source_id`, `operation` = uppercased protocol).
5. `"{port}/{protocol}"` not in target's `published_ports` → `PORT_UNPUBLISHED` (`entity_id` = `target_id`, `detail` = `"{port}/{protocol}"`, `operation` = uppercased protocol).
6. No `ALLOW_EGRESS` edge `source_id→target_id` → `EGRESS_DENIED` (`entity_id` = `target_id`, `detail` = `source_id`, `operation` = uppercased protocol). **Run before** zone blocking even when both would apply.
7. Source zone `edge`, target zone `internal`, and `block_edge_to_internal` → `ZONE_BLOCKED` (`entity_id` = `source_id`, `detail` = `target_id`, `operation` = uppercased protocol).
8. Target zone `internal`, `require_tls_on_internal`, target container has label `net:tls` (from `BIND_LABEL`), and not `use_tls` → `TLS_REQUIRED` (`entity_id` = `target_id`, `detail` = **empty**, `operation` = uppercased protocol). Do **not** emit `TLS_REQUIRED` when the target lacks `net:tls` even if other TLS policy flags are set.

`operation` on `CONNECT_PROBE` findings: steps **1–2** always use `operation` = `""`. Steps **3–8** must set `operation` to the probe `protocol` **uppercased** (`tcp` → `TCP`; never pass through lowercase). All non-probe kinds and post-replay audits use `operation` = `""`.

## Post-replay audits (after all events)

Compute audit `event_seq` after replay finishes:

`audit_event_seq = max(seq from every decoded event row after sort, including rows skipped only because of duplicate event_id) + 1`

Update `max(seq)` **before** testing duplicate `event_id` skip so skipped rows still contribute their `seq` to the audit baseline.

**Audit append order** (before the final `finding_id` sort): emit `BRIDGE_GAP` findings first (bridge network creation order, then sorted edge and internal member lists), then `OVERLAY_ASYMMETRY` (overlay network creation order), then `OPEN_DMZ_PATH` (`container_id` ascending), then `INSPECT_UNBOUND` (`container_id` ascending).

Use that single value for **every** post-replay audit finding (`BRIDGE_GAP`, `OVERLAY_ASYMMETRY`, `OPEN_DMZ_PATH`, `INSPECT_UNBOUND`). Never use `0`, never reuse a probe `event_seq`. Examples: `docker_network_connectivity_debugger_scenario_16` max `seq` 5 → audit `event_seq` 6; `docker_network_connectivity_debugger_scenario_02` max `seq` 7 with `BRIDGE_GAP` also uses `8`; `docker_network_connectivity_debugger_scenario_19` emits both dmz audits at `5` when max `seq` is 4. Audit findings always use `operation` = `""`.

**BRIDGE_GAP** — For each `bridge` network (in network creation order), list edge members and internal members on that network (each list sorted by `container_id`). For every `(edge, internal)` pair, if no `ALLOW_EGRESS` edge `edge→internal` exists in final replay state, emit one finding (`entity_id` = internal `container_id`, `detail` = edge `container_id`). **Skip** the pair when that egress edge is present — including when a `ZONE_BLOCKED` probe finding was recorded for the same containers (policy block does not remove the egress edge). Emit **at most one** `BRIDGE_GAP` per `(edge_container_id, internal_container_id)` pair across all bridge networks (deduplicate before appending).

**OVERLAY_ASYMMETRY** — For each `overlay` network (at most one finding per `network_id`), if it has at least one edge member and one internal member (each list sorted by `container_id`), and no `ALLOW_EGRESS` exists from any internal on that network to any edge on that network, emit (`entity_id` = first internal in sorted order, `detail` = first edge in sorted order).

**OPEN_DMZ_PATH** — For each `dmz` container with at least one published port and without label `net:inspect`, emit (`entity_id` = `container_id`, `detail` = lexicographically first entry in its `published_ports` set). At most one per dmz container regardless of port count.

**INSPECT_UNBOUND** — For each `dmz` container without label `net:inspect` that has inbound `ALLOW_EGRESS` from any `edge` container, emit (`entity_id` = `container_id`, `detail` = **empty**). At most one per dmz container.

## connectivity_risk field

Set **only** from each container's `zone`. Findings — including `CONNECT_PROBE` failures, duplicate registrations, and post-replay audits — must **never** raise or lower `connectivity_risk`.

Allowed values only: `none`, `elevated`, `critical`.

- `none` — zone is `internal` (unchanged even when findings reference that container)
- `elevated` — zone is `edge` (unchanged by findings)
- `critical` — zone is `dmz` (unchanged by findings)

## Finding kinds

Use the exact `kind` strings in the table below. Do not invent synonyms (for example use `NETWORK_PARTITION`, not `NO_SHARED_NETWORK`; use `OPEN_DMZ_PATH`, not a custom dmz label).

`finding_id` = `{scenario_id}::{entity_id}::{event_seq:04d}`.

| Kind | When | `entity_id` | `detail` |
|------|------|-------------|----------|
| `DNS_UNRESOLVED` | alias fails on shared networks | `source_id` | dns_alias |
| `NETWORK_PARTITION` | no shared network | `target_id` | source_id |
| `PORT_UNPUBLISHED` | port not published | `target_id` | port/protocol |
| `EGRESS_DENIED` | no ALLOW_EGRESS edge | `target_id` | source_id |
| `UNKNOWN_CONTAINER` | unknown container (probe: missing id) | missing id | event kind |
| `UNKNOWN_NETWORK` | unknown network | `network_id` | event kind |
| `DUPLICATE_CONTAINER` | second REGISTER_CONTAINER | `container_id` | empty |
| `DUPLICATE_NETWORK` | second CREATE_NETWORK | `network_id` | empty |
| `DUPLICATE_JOIN` | duplicate JOIN_NETWORK | `container_id` | network_id |
| `DUPLICATE_EGRESS` | duplicate ALLOW_EGRESS | `to_container` | from_container |
| `ZONE_BLOCKED` | blocked edge→internal | `source_id` | target_id |
| `TLS_REQUIRED` | internal target with `net:tls` label but probe without TLS | `target_id` | empty |
| `BRIDGE_GAP` | missing egress on bridge | internal `container_id` | edge container_id |
| `OVERLAY_ASYMMETRY` | overlay lacks internal→edge egress | first internal | first edge |
| `OPEN_DMZ_PATH` | dmz without net:inspect label | `container_id` | port/protocol |
| `INSPECT_UNBOUND` | dmz with edge inbound, no inspect | `container_id` | empty |

Sort `findings` by `finding_id` ascending with **stable** ordering when `finding_id` values duplicate (preserve append order; see quick reference). `status` = `VALID` iff no findings.

Across all bundled scenarios together, the report must use every kind at least once.

## Build and allowed paths

Use `make build` and `make run` only. The Go binary must live at `/app/build/docker-network-connectivity-debugger` (`go build -o build/docker-network-connectivity-debugger`). Do not leave `/app/docker-network-connectivity-debugger` or other stray top-level binaries.

`/app/cmd/docker-network-connectivity-debugger/main.go` must embed these **verbatim string literals** in source (not `filepath.Join`, not variables built at runtime): `"/app/data"`, `"/app/build/docker_network_connectivity_debugger_report.json"`, `"docker_network_connectivity_debugger_manifest.json"`, and `"docker_network_connectivity_debugger_capture.cnx"`. No shell substitution (`$()`, `bash -c`, etc.).

## Report

Write `/app/build/docker_network_connectivity_debugger_report.json` per `/app/docs/DOCKER_NETWORK_CONNECTIVITY_DEBUGGER_SCHEMA.md`. UTF-8 compact JSON, LF only, exactly one trailing newline; use `[]` never null. Identical `/app/data` bytes must produce byte-identical reports across consecutive `make run` invocations.
