# Dragon Cup tournament rulebook excerpt

The tournament uses a 5x5 board for reduced adjudication records and `tournament-area-2026` area scoring. A game is closed only after two consecutive passes in the main line. Branches written for review or commentary replay from their stated main-line snapshot and are not part of the final position. Final adjudication must compare the rules-engine replay with the independent adjudicator policy. Records from the 1999 archive may use a single legacy result token on the score line, and those archive records remain valid inputs.
