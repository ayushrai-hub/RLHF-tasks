# Refer Friends inside Pi Lens (Hard referral)

Extracted rules from the bundled PRD:

- The hard-referral flow requires 3 successful referrals before locked features unlock.
- PDF Bank locks when the unique PDF download count reaches the configured threshold.
- Simulations and mindmaps each have their own independent configured thresholds.
- Once the referral quota is completed, PDF Bank, Simulations, and Mindmaps all unlock together.
- Users with only partial referral progress must remain locked if any surface has exhausted its free quota.
