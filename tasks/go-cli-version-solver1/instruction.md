PUBLISH pkg version registers that a version exists. Versions use semver major.minor.patch with optional pre-release suffix (e.g. 1.0.0-beta.1). Pre-release versions sort below their release counterpart (1.0.0-beta.1 < 1.0.0) but above lower releases (0.9.9 < 1.0.0-beta.1). Prints OK. YANK pkg version marks a version as yanked so resolution ignores it, prints YANKED pkg version. DEPEND pkg version depPkg constraint declares a dependency. Prints OK. ADD pkg constraint adds a top-level requirement, prints OK. Supported constraints: ^X.Y.Z (same major, minor/patch can increase), ~X.Y.Z (same major.minor, patch can increase), >=X.Y.Z (at least), bare X.Y.Z (exact), >=X.Y.Z <A.B.C (range). Constraints without a pre-release tag do not match pre-release versions. Constraints with a pre-release tag (like ^1.0.0-beta.1) match pre-releases within the same major.minor.patch.

RESOLVE picks the highest compatible non-yanked version for each package satisfying all constraints at once. Dependencies resolve transitively with constraint intersection. When the highest version causes a transitive conflict, backtrack to the next lower version. On success print RESOLVED then one line per package alphabetically as pkg version. On failure print CONFLICT pkg constraint where constraint is the FIRST constraint added for that package. State accumulates across multiple RESOLVE calls within the same session (published versions, dependencies, ADD'd requirements all persist). LOCK pkg version pins a version, prints LOCKED pkg version. If it violates a constraint prints LOCK_ERROR pkg version. UNLOCK pkg removes a lock, prints UNLOCKED pkg or UNLOCK_ERROR pkg if none. UPGRADE pkg moves a locked package to highest compatible, prints UPGRADED pkg newVersion or NO_UPGRADE if already best. REMOVE pkg removes from requirements and lock, prints REMOVED pkg.
