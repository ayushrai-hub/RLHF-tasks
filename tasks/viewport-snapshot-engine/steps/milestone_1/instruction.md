You are building the layout pass a browser agent runs to learn where each element sits on screen. Write it at `/app/viewport.py`, run as `python3 /app/viewport.py <scenario> <output>`, standard library only, integer arithmetic. A scenario is JSON with an integer `milestone` and a `cases` list; each case has a `root` node and (from milestone 2) a `viewport`. A node carries a string `id`, an optional `tag`, and a `box` of `[x, y, w, h]` that is its border box; `x, y` are its top-left relative to the parent's content origin and `w, h` its size. It may also carry `border` and `padding`, each `[top, right, bottom, left]` widths defaulting to zeros, a `scroll` `[sx, sy]` defaulting to `[0, 0]`, and `children`. Write `{"answers": [...]}` to the output as canonical JSON via `json.dumps(result, sort_keys=True, separators=(",", ":"))`, one entry per case.

This milestone resolves absolute geometry. The root's box top-left is the viewport origin. A node's content origin, where its children's coordinates are measured from, is its border-box top-left moved inward by its left and top border plus padding, then shifted by the negation of its own scroll. Return a map from each node id to its absolute border box `[x, y, w, h]`.
