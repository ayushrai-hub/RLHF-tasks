This milestone packs the snapshot into a checksummed binary frame, built over the milestone 3 records in index order. Counts and lengths below are unsigned LEB128 varints, and a string is its UTF-8 byte length as a varint followed by those bytes.

The frame opens with the ASCII bytes `DVS1`, then a version byte `0x01`, then a flags byte, then the record count. The flags byte sets bit 0 when the record count is odd, bit 1 when any record has a non-empty role, and bit 2 when any record has a non-empty label; all other bits stay zero. Each record then contributes, in order, its `id`, `tag`, `role`, and `label` as length-prefixed strings, then its four `rect` values, each as the signed difference from the previous record's matching value (the first record differences against zeros) encoded as signed two's-complement LEB128, not zig-zag.

Finally append a four-byte big-endian CRC over every preceding byte: a CRC-32 with polynomial `0x814141AB`, most-significant-bit first, no input or output reflection, and initial and final values all ones. Return `{"sha256", "crc", "length", "records"}`: the lowercase hex SHA-256 of the whole frame, the CRC as an integer, the frame byte length, and the record count.
