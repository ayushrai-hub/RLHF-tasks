# Workspace Map

- /app/cmd/fleetrisk: CLI entry point.
- /app/internal/config: JSON config loading and typed config structs.
- /app/internal/features: feature extraction for service calls and sensor windows.
- /app/internal/model: ensemble scoring and calibration.
- /app/internal/report: output row structs and writing helpers.
- /app/data: fixed service-call, sensor-window, history, label, and site-capacity inputs.
- /app/config: model and dispatch policy configs, including part inventory and transfer policy.
- /app/docs: operator-facing contracts for the scorer.
