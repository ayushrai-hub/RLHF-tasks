Repair sources under `/app/environment` so `/app/logrecover` emits a compliant report at `/app/output/recovery_report.json`. The verifier rebuilds with Go under `/app/environment`, reruns the driver on the pack, then grades with pytest. Build and run steps are documented in `/app/environment/README.md`. Bundled scenario ids and quorum_need values are in the pack fixture.

The report is a JSON object and must carry schema_version, recovery_budget_ms, and per-scenario recovered_events, quorum_size_seen (compare against each scenario quorum_need in the pack), recovery_elapsed_ms, data_loss_events (0 for each bundled scenario), partition_healed (boolean true), merge_mode, and canonical_digest_hex as 64 lowercase hex characters. Grading runs python -m pytest with --ctrf /logs/verifier/ctrf.json. Record layout lives in the environment sources.
