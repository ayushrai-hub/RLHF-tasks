Write a generic FSK decoder function. For this milestone, the test runner will feed your decoder a carrier modulated with FSK. It will start with a preamble of at least 4 bits of the mark frequency for you to lock and to calibrate your demodulator. Then the test fixture will send an arbitrary ASCII message of length from 2-10 bytes, for example, "Hello!!!" or "Azure" using 8N1 UART encoding. Your decoder must correctly parse the start bits, data bits, and stop bits to return the content sent by the test fixture. You have been provided with /app/headers/fsk_decoder.h and a scaffold file /app/fsk_decoder.c. Implement the required API in the fsk_decoder.c file. This file will be compiled with gcc and will not be a Zephyr build.

The Carrier Frequency is selected by the test fixture within the range 58.0 Hz to 62.0 Hz. The modulation is Frequency-Shift Keying (FSK) with a mark frequency of the carrier + 0.05Hz and a space frequency of carrier - 0.05Hz which results in mark space separation of 0.1Hz. Transmission Preamble: The signal will begin with a 3 to 4 second idle period (continuous Mark) before the first character's Start Bit is transmitted. The bits time is in the range of 58 to 62 frames which is approximately 1.0 baud ± 3.3%. The bit time can vary over the message. The message is encoded as NRZ UART framing with standard 8N1 (1 Start Bit, 8 Data Bits sent LSB first, No Parity, 1 Stop Bit).

In this milestone you must implement the function fsk_decoder_init(void) - anything you need you can put here but the function must be present even if empty. You must also implement int fsk_decoder_process_freq(double current_freq, char *decoded_char). In this function you decode one character. If no character is found, you return 0. If a character is found you return 1 and write the character into the byte pointed to by decoded_char.
