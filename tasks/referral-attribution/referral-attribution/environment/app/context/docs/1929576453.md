# Refer Friends inside Pi Lens (Hard referral)

Extracted attribution rules from the PRD:

- Eligible referral activity is limited to `signup` and `signin` events with a known referral code.
- Existing users signing in through the referral link still count as successful referrals.
- Attribution idempotency is scoped to the same referrer/referee pair. A duplicate event for the same pair counts once.
- The same referee can legitimately credit two different friends' referral links; do not deduplicate by referred user globally.
- Self-referral is not allowed on the same device or another device. Compare the event `referredUserId` to the referrer's `userId` and ignore the event when they match.
- Report output must remain deterministic: rows sorted by `userId`, and each row's `referredUsers` sorted.
