Closure semantics

Version selection follows depot latest unless a dated amendment pins a module series for a specific root matrix entry. Amendment prose of the form For root matrix entry X, module Y must remain on series V applies to any entry listed in the live root index, not only the original fixtures. Storage class legacy may trigger host alias overrides documented in the March amendment after closure completes.

Emitted tables share one repo_key namespace across lock, repo, and checksum artifacts. Sort rows by module_id ascending, then repo_key ascending (checksum rows by repo_key only).

Tampered output files under /app/output/ are replaced on the next apply. Long rotations across entries must preserve per-entry pins when returning to a prior matrix slot.
