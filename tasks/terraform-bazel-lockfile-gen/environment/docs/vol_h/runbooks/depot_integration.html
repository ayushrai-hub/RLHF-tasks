Depot integration

The pipeline fetches module metadata from the sidecar catalog URL documented in artifact_shapes.md. Closure walks must start from the active root fixture seed list and expand transitive dependencies from catalog deps edges — never materialize every package row as if it were installed.

Checksum rows must copy the catalog checksum field for each resolved module. Repo URLs default to each package repo value unless an amendment applies a host alias after closure completes.

When a dependency edge includes @version, that pin propagates to the named module before selecting a version for unpinned edges. When the same module is reached through multiple explicit @version pins, choose the lowest semantic version present in that package's version list, and rebuild the affected closure if a lower pin is discovered after the module was first seen.
