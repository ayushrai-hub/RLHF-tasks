# Schema authority

The IDL files define current canonical descriptors. The migration maps define accepted legacy aliases. The input manifest determines which authority files participate in regeneration and input-digest calculation. The v1 user descriptor `acme.user.event.v1` maps to `acme.activity.event.v2`, and the v1 audit descriptor `acme.audit.envelope.v1` maps to `acme.audit.envelope.v2`.
