We need a Rust circuit breaker registry listening on `0.0.0.0:8080`, driven entirely by a simulated microsecond clock (`now_us`) with no wall-clock time in resilience logic. The environment ships vendored crates under `/opt/vendor` for offline builds. Create the Cargo project at `/app`, build in release mode, run the server detached, and write its PID to `/app/server.pid` so restarts can replace the old process cleanly.

Milestone 1 covers health and clock endpoints, simple-policy breaker registration, failure reporting, and single-breaker route checks. When a simple breaker is OPEN and enough simulated time has passed since `last_state_change_us` (at least `recovery_timeout_us`), a check or clock advance must move it to HALF-OPEN before deciding allowance. HALF-OPEN checks return `allowed: true`; a successful report closes the circuit, a failed report reopens it. Serve an HTML dashboard at `/` with canvas elements `closedChart`, `openChart`, and `breakersChart`. Field types, status codes, and JSON shapes are in `/app/spec/SPEC.md`.
