# WaveBench Adaptive-CFL Validation Dossier

Document revision 0.9.5 — Numerical Stability Working Group

This dossier is the authoritative source for every stability constraint the static
auditor must enforce against the `wavebench` Cargo workspace. Constraints are recorded
in several historical formats: section-heading `AUDIT-RULE` lines, reviewer-comment
`STABILITY-BOUND` blockquotes, method-note `CFL-ANNOTATION` paragraphs, and errata-table
`GUARD-REQUIRED` / `PROHIBITED-COMBINATION` rows. Annotations whose `status` is anything
other than `active` (superseded, withdrawn, rejected, draft, example) are historical and
must be ignored.
