We need a clean settlement feed before billing can start. Read the raw meter logs under `/app/raw-events` and the SQLite catalog at `/app/catalog/meter_catalog.db`, then write `/app/output/normalized-events.jsonl`.

The output should contain one JSON object per accepted meter event with these fields: `event_id`, `observed_at`, `account_id`, `meter_id`, `service_month`, `district`, `adjusted_kwh`, and `source_quality`. Keep the newest revision for duplicate event ids, break any same-revision tie with the higher source priority, ignore events whose quality is not `valid` or whose meter was not active at the observed timestamp, multiply `kwh` by the meter multiplier, round `adjusted_kwh` to three decimals using half-up rounding, derive `service_month` from the UTC timestamp, and sort rows by service month, account id, observed timestamp, then event id.
