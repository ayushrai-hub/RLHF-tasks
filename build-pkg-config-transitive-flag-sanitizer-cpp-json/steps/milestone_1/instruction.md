The release tooling in `/app` has a small C++ `pc-sanitize` utility, but the first pass still reads pkg-config files too loosely. Build it with CMake and repair the `parse` command so it can be trusted as the metadata source for later dependency checks.

For this stage, `pc-sanitize parse --pc-dir DIR --manifest FILE --out FILE` should scan every `.pc` file in `DIR`, expand simple `${name}` variables before tokenizing flags, extract package names from comma-separated `Requires` and `Requires.private` entries while ignoring version constraints, and write the parse JSON described in `/app/docs/contract.md`. Missing optional fields should become empty arrays or empty strings, package objects should be sorted by package name, and malformed or irrelevant lines should not crash the command.
